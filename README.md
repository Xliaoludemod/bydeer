## 1. 这是什么

个人摄影作品集网站，纯展示用。分三个内容层：

- **首页**：首屏轮播 → 第二区域（分栏索引 + 右侧展示图）→ 第三区域「片柜」（筛选 + 系列卡片）
- **专属片柜**：按分区（银盐·胶片 / 像素·数码 / 动态·影像）列出成套系列
- **朋友们**：朋友投稿作品的独立入口（首页右上角图标进入），不和自己作品混在一起

内容规模（2026-09-30）：自己的作品 9 套 121 张（胶片 6 套 101 张 + 数码 3 套 20 张）、朋友投稿 5 套 26 张，合计 14 套 147 张照片；另有首屏轮播图 3 张。动态·影像分区目前为空（显示「视频整理中」）。

## 3. 技术形态

- **纯静态**：HTML / CSS / JS / 图片，**没有后端、没有数据库、不需要构建**。
- 没有用任何框架和第三方库（`lib/` 里有少量自用脚本）。
- 所有页面共用一个样式表 `css/style.css` 和几个 JS；数据全部集中在 `js/data.js`。
- 图片显示用「同目录 `th/` 子文件夹、同名文件」的约定：代码自动找缩略图，找不到就退回大图，**不会破图**。

## 5. 唯一配置源：`js/data.js`

**改网站内容只动这一个文件，改完不需要构建。** 里面是一个全局对象 `SITE`：

- `SITE.social[]` —— 导航社交图标。`url` 填 `http(s)://` 开头 = 新窗口外链；填站内路径（如 `friends.html`）= 当前窗口跳；留空或 `#` = 不跳（填了 tip 则点击复制号码）
- `SITE.heroSlides[]` —— 首屏轮播图（按数组顺序出场）
- `SITE.indexPreview[]` —— 首页第二区域**默认**展示图：放 1 张 = 固定显示；放 2 张以上 = 每 4.5 秒轮换；**不能留空**（空灰框像网站坏了）
- `SITE.sections[]` —— 三个分区（film / digital / motion），每项可带：
  - `preview` —— 鼠标悬停该分区时右侧展示的图（一条路径，或一组路径轮换；没配则保持默认那张）
  - `cabinet` —— 点它跳去的专属片柜页，如 `cabinet.html?sec=film`（不填 = 点了没反应）
  - `empty` —— 该分区一套都没有时的占位文字（motion 填的是「视频整理中」）
- `SITE.series[]` —— 所有系列，顺序 = 片柜出场顺序。每套：
  - `slug`（也是独立页文件名）/ `title` / `section` / `cover` / `film`（胶片型号，显示在卡片名下）
  - `photos[]` 每张：`src`（必填）、`gear`（器材，必填）、`work`（作品名，灯箱顶部）、`tags`（搜索燃料）、`note`（展签，暂未在页面显示）、`link`/`code`（网盘下载，可空）
  - **投稿专用**：`credit: "© 某某"`（署名）、`searchable: false`（不进搜索）、`meta`（系列页标题下小字）
  - 某一张照片单独不进搜索：在那张里写 `searchable: false`

> ⚠️ 约定：**用户提供的文字一律照抄**（器材、系列名、胶片名、署名），不要"规范化"大小写。

## 7. 照片规格与命名

```
photos/<分区>/<系列>/NN.jpg      大图  长边 2560 · 质量 88 · 约 1MB   ← 灯箱/放大
photos/<分区>/<系列>/th/NN.jpg   缩略  长边 900  · 质量 82 · 约 100KB  ← 图墙/卡片
photos/首页/0N.jpg               首屏  长边 3200 · 质量 88
```

- **单张硬上限 3MB**；文件名保持「同目录、同名」，缩略图放同目录 `th/` 下
- 胶片扫描件才裁黑边（prep 脚本加 `--crop`），数码原片不裁
- 卡片按照片原始比例显示、不裁切；系列页图墙「同一行等高、按比例分宽」

## 8. 加新照片 / 新系列的流程

1. 原片整理到一个文件夹（素材库 `N:\2小鹿的网站\片库\`；**素材库只读，只复制不改动**）
2. 跑 `tools/prep_photos.py "原片夹" "photos/分区/系列名"` 生成大图 + 缩略图
3. 在 `js/data.js` 里加这套系列（插在自己作品的分组里，投稿的加 `credit`）
4. 跑 `tools/build_series.py` 生成独立页 + 更新版本号（全站 html 的 `?v=` 统一升一号）
5. 提交 + 推送（见 §9）

其它工具：`read_exif.py`（读拍摄信息）、`make_preview.py`（拼九宫格总览，别逐张看图）、`make_placeholders.py`（占位图）。

## 9. 更新与发布（上线）

- 发布方式 = **GitHub Pages**：仓库 main 分支根目录直接发布，推完约 1–2 分钟生效。
- 更新流程：改文件 → `git add -A` → `git commit` → `git push`。我可以直接代办。
