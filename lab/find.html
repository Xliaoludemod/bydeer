找照片

照片多起来以后，翻是最累的。这里可以直接说人话找—— 「想看点安静的、水边的」「有没有雾」都行。
AI 看过每一张照片，把它看见的东西写成了词和一句话；这里拿它来检索。 所以它是秒回的，也不花任何人的钱。

换个说法也行：傍晚 / 日落 / 黄昏　·　雾 / 朦胧 / 看不清　·　夜 / 黑 / 暗　·　蓝 / 冷　·　暖 / 黄
没找到 换个说法试试 —— 或者说得更松一点，比如只写「水边」。
AI 在哪儿：在"读照片"这一步 —— 每张照片被看过一遍，写下关键词和一句展签。 访客的浏览器里不跑任何模型，所以打开就秒回，不花流量也不花钱。
这是为什么：在访客浏览器里跑真模型要下载 30–100MB，你的链接是用聊天软件发给朋友的——等 20 秒，人就走了。
你加照片时：把照片丢给我（或任何能看图的 AI），让它按这个格式产出「关键词 + 一句展签」， 填进 data.js 的 tags / note 两个字段就行。200–400 张可以分批跑。
